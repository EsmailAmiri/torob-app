# ترب همراه

نمونه مستقل از ظاهر ترب با React 19 و Vite، برای چالش دستیار خرید حضوری تهران. این برنامه به حساب یا API رسمی ترب متصل نیست.

## اجرا

نیازمندی: Node.js نسخه 22.12 یا جدیدتر.

```sh
npm install
npm run dev
```

آدرس محلی در خروجی Vite چاپ می‌شود. برای ساخت نسخه نهایی:

```sh
npm run build
npm run preview
node --test tests/catalogue.test.js
```

## امکانات پیاده‌شده

- صفحه اصلی با ساختار، لوگو و رنگ‌بندی ترب؛ رابط فارسی راست‌به‌چپ و مناسب موبایل.
- جست‌وجو در تمام ۲۲۵٬۹۰۳ محصول دیتاست، فیلتر بودجه و برند، مرتب‌سازی قیمت.
- مقایسه مشخصات حداکثر سه محصول و ذخیره علاقه‌مندی‌ها در مرورگر.
- اتصال دقیق ۳۳۱٬۵۰۶ آفر به ۶٬۴۷۶ فروشگاه؛ قیمت‌ها با واحد تومانِ ستون `price_toman` حفظ شده‌اند.
- صفحه فروشندگان، فاصله جغرافیایی، انتخاب محله یا موقعیت فعلی، شعاع، ساعت کاری و شرایط خرید اعتباری.
- نقشه Leaflet با کاشی‌های OpenStreetMap و مسیریابی در Google Maps.
- دستیار محلی برای اجرای جست‌وجو، بودجه، برند و محله از متن فارسی؛ تغییر فیلترها در پنل دستیار دیده می‌شود.
- سناریوهای مشخص و آزمایشیِ موجودی، عدم موجودی و عدم پاسخ فروشنده؛ جایگزین‌یابی با آفرهای همان محصول.

## داده و معماری

فایل اصلی `starcoach-dataset-v16-cap300-csv.zip` در پوشه بالاتر است. داده‌های آماده در `public/data` قرار دارند و اجرای معمول به Python نیاز ندارد. برای بازسازی داده‌ها با Python 3:

```sh
npm run data
```

`scripts/prepare_data.py` هر سه جدول را کامل پردازش می‌کند. شماره‌های جعلی و کانال‌های تماس به خروجی وب منتقل نمی‌شوند. ایندکس جست‌وجوی فشرده حدود ۱۷ مگابایت است و فقط هنگام ورود به نتایج در Web Worker دریافت می‌شود؛ پس از بارگذاری، فیلتر و جست‌وجو محلی‌اند. جزئیات محصول در ۲۵۶ بخش ذخیره شده و هنگام نیاز بارگذاری می‌شوند. فشرده‌سازی gzip هم در سرورهایی که خودکار باز می‌کنند و هم در میزبان استاتیک پشتیبانی می‌شود.

`src/catalogue.js` شامل ابزارهای داده، زمان تهران و فاصله است. `src/main.jsx` جریان‌های رابط و `src/style.css` طراحی واکنش‌گرا را نگه می‌دارند. کد و CSS نقشه جدا و هنگام باز شدن نقشه دریافت می‌شوند. فونت وزیرمتن محلی است؛ تصاویر محصول به آدرس‌های موجود در دیتاست وابسته‌اند و برای خطای تصویر، جایگزین متنی داریم.

## مرزهای نسخه فعلی

- دستیار قواعد محلی دارد و به LLM متصل نیست؛ مشاوره تخصصی و فهم آزاد زبان هنوز کامل نیست.
- هیچ تماس یا پیامی به فروشنده ارسال نمی‌شود؛ شماره‌های دیتاست جعلی‌اند. استعلام‌ها صریحاً شبیه‌سازی هستند و تأیید واقعی محسوب نمی‌شوند.
- آفر ثبت‌شده، زمان تغییر قیمت و موجودی تأییدشده جدا نمایش داده می‌شوند؛ اطلاعات قیمت زنده نیست.
- ساعات کار اعلام‌شده‌اند؛ وضعیت باز بودن بر اساس زمان تهران است و تعطیلی استثنایی را پوشش نمی‌دهد.
- فاصله‌ها مستقیم‌اند؛ زمان و فاصله مسیر واقعی از سرویس مسیریابی گرفته نمی‌شود.
- شعاع، ساعت کاری و خرید اعتباری روی فروشندگانِ محصول انتخاب‌شده اعمال می‌شوند؛ بودجه و برند روی نتایج محصولات.
- اطلاعات پرداخت خالی به معنی عدم پشتیبانی نیست؛ کانال `unknown` به‌عنوان پذیرندگی حضوری نمایش داده نمی‌شود.
- ۶۰ نتیجه اول نمایش داده می‌شود؛ محدودکردن جست‌وجو به نتایج دقیق‌تر کمک می‌کند.
- علاقه‌مندی‌ها محلی‌اند؛ حساب کاربری، همگام‌سازی بین دستگاه‌ها و تأیید موجودی واقعی هنوز پیاده نشده‌اند.

## بررسی انجام‌شده

مسیرهای جست‌وجو، تغییر شرایط از گفتگو، ذخیره و ماندگاری پس از بازخوانی، مقایسه مشخصات، فروشندگان، نقشه، سناریوی عدم موجودی و پیشنهاد جایگزین در مرورگر بررسی شده‌اند. رابط در اندازه‌های ۱۴۴۰ و ۳۹۰ پیکسل بررسی شده و اسکرول افقی نداشته است. آزمون‌های واحد، قواعد فارسی، زمان تهران و شیفت شبانه را پوشش می‌دهند.

برای نسخه محصول نهایی: اتصال امن سمت سرور به مدل زبانی، کانال مجاز استعلام واقعی، جست‌وجوی سمت سرور برای کاهش دانلود اولیه و سناریوی دموی پنج‌دقیقه‌ای باقی می‌ماند.
